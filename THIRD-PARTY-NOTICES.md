# Third-party notices for the `encypher` command line tool

`encypher`, the `encypher_client` C library and its header are licensed
under the Apache License 2.0; see `LICENSE`. The binaries also contain the
open-source crates listed here, each under its own license. This file is
the notice those licenses require, and nothing in it changes the terms of
`LICENSE`.

The list is generated from the locked dependency graph of the three crates
the release builds (`encypher-cli`, `encypher-client`, `encypher-client-ffi`)
for every target, by `packaging/release/third_party_notices.py write`. It
covers the crates whose code is linked into the shipped binaries; crates
used only to build or test them are not distributed and are not listed.
Some crates are compiled only for one operating system, and a given binary
carries only those.

Where a crate offers a choice of licenses, Encypher takes the Apache
License 2.0 where it is offered and the MIT license otherwise. Each crate
below names the license texts that apply to it, and "License texts" at the
end carries each of those texts in full. A text that several crates share
appears once and is named by every crate that uses it.

## Reciprocal licenses

have to comply with. These crates offer a reciprocal license as one
